# Bounded stable-OD node-pair QVDF overrides

The dictionary contains 49,336 directed pairs and the bounded PLF, QDF, n,
s, cp, cd, alpha, and beta for AM, midday, and PM. It also stores the
calibrated cutoff speed in mph where the verified assignment supplied one.

The workflow applies the dictionary after network mapping in profile mode
2. The automatic transfer carries cutoff speed when the base calibration
provides it. The source manifest records coverage, bounds, and checksums.
