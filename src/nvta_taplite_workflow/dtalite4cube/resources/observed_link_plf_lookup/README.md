# Observed-link PLF lookup

`observed_link_plf_overrides.npy` is generated by CBI network-QVDF
calibration. It is a sorted NumPy structured array keyed by the directed
`(from_node_id, to_node_id)` pair.

The three values are dimensionless `plf_am`, `plf_md`, and `plf_pm`. For the best-match
GMNS link of an observed TMC, CBI uses the accepted average-weekday episode
QDF when that period has observed congestion. If no average-weekday
congestion episode is accepted, CBI sets `QDF = 1 / H`, which makes
`PLF = 1`.

The converter memory-maps this file, performs vectorized packed-key lookup,
and overrides only `vdf_plf`. All other QVDF parameters continue to come
from the authoritative link-type row in `link_qvdf.csv`.
