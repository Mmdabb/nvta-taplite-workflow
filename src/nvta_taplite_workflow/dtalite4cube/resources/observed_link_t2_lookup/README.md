# Observed-link episode-boundary lookup

`observed_link_t2.npy` is generated by CBI network-QVDF calibration. It is a
sorted NumPy structured array keyed by the directed best-match GMNS
`(from_node_id, to_node_id)` pair for each observed TMC.

Each period has decimal-hour `observed_t0_hour_*`, `observed_t2_hour_*`, and
`observed_t3_hour_*` fields. A finite triplet comes only from one representative
accepted weekday-average congestion episode. If more than one accepted episode
exists for a TMC and period, the representative is selected by lowest minimum
speed, then longest duration, then earliest T2, then episode ID. T0 and T3 keep
their observed values even when they extend outside the assignment period;
TAPLite uses them only to recover episode asymmetry and clips the emitted
profile to the period. No accepted episode is stored as a `NaN` triplet.

During congestion-boundary assignment, a finite observed triplet overrides
`t0_hour`, `t2_hour`, and `t3_hour` on the matched link. A `NaN` triplet
explicitly clears all three fields so spatial or ML completion cannot create
congestion on a matched TMC with no accepted weekday-average episode.
